# 项目记忆索引

## 项目：gamepad-agent
Windows 游戏手柄→键盘映射工具，用 8BitDo 手柄操作 AI Agent CLI（opencode/claude code/codex 等）的批准/取消/导航，RB 键触发 Win+H 语音输入。

运行：`python main.py`（目录 C:\Users\LL\Desktop\gamepad-agent，先 `pip install pygame`）
